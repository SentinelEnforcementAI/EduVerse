# Platform tour

A screenshot of every screen in Sentinel Watch, grouped by feature area, with
the feature rundown alongside. Captured from the running app against the seeded
demo trust — running software, synthetic data, no real child.

- **[`gallery.html`](./gallery.html)** — the tour as one page. Open it in a
  browser (or serve `docs/demo/tour/`); the images live in `screens/`.
  For a single self-contained file to share, run `pnpm demo:tour:embed`.
- **[`screens/`](./screens/)** — the individual screenshots, `NN-name.jpg`.

Everything here is regenerated by one command — see
[`tooling/screenshots/`](../../../tooling/screenshots/README.md):

```bash
pnpm db:deploy && DEMO_PUPILS=220 DEMO_MONTHS=12 pnpm db:seed:demo
pnpm build && pnpm --filter web start &
pnpm demo:tour
```
