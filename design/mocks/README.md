# Design mocks

Reference material for DESIGN.md (v2 rebrand).

- `brand-system-12-product-ui.png` — product UI expression from the brand
  system deck (page 12): dark-on-light contrast, KPI stat row, signal trend,
  needs-attention list.
- `brand-system-13-information-design.png` — priority model and information
  design principles (page 13): severity tints with labels, context before
  colour.

The two full dashboard mocks (school overview, trust overview) were supplied
by the founder as images and reviewed during the rebrand slice; they were not
provided as committable files. Where the mocks and DESIGN.md disagree
(pupil photographs, numeric risk scores), DESIGN.md wins — the deviations
are deliberate. See DESIGN.md at the repo root.

Brand assets (mark variants, app icon) are extracted from
`Sentinel_Watch_Brand_System.pdf` and live in `apps/web/public/brand/`.
